# 网课笔记 · Online-Class-Notes

**把网课里老师讲的话，自动变成一份带时间戳、能排版、能导出的文字笔记。**

录音 → 本地离线识别 → 实时转写 → 一键整理成提纲（可选接大模型写成体系化终稿）→ 排好版导出 Markdown / HTML。
看网课视频时挂一个悬浮圆钮随时截屏，截图自动交给视觉模型读懂，直接写进笔记。

> **语音识别全程离线**：不联网、不上传，录音只存在手机私有目录里。
> 只有你主动点「AI 整理」或「AI 分析这张图」时，才会把**文字**或**那一张图**发给你自己配置的服务商；不填 API Key 就完全离线。

## 功能

| 功能 | 说明 |
|---|---|
| 一键记录 | 首页大按钮开始，前台服务运行，息屏 / 切到别的 App 都能继续记 |
| 实时转写 | VAD 自动断句 + SenseVoice 中文识别，每句话带 `[分:秒]` 时间戳 |
| 自动标重点 | 听到「重点 / 必考 / 注意 / 记住 / 考试」等词自动标星高亮 |
| **知识点笔记** | 一键把整段转写**整理成提纲**：自动分节、提炼要点、抽术语当小标题，全程本地离线，秒出结果 |
| **AI 体系化整理（可选）** | 接大模型把整堂课编辑成一份成体系的终稿：知识框架 → 大节 / 小节 → 术语公式表 → 易错点 → 一句话总结 → 作业（栏目随内容走，没有的就不硬凑）。按「**不看录播、只听这份笔记也能学会**」来写：每个知识点要讲清是什么 / 为什么 / 怎么用 / 哪里容易错，而不是把老师的话压缩一遍；长课走「**先出一份全局提纲、再逐节并行成文**」，每节有自己的素材和篇幅预算，两小时的课也不会被压成骨架；**成稿不带时间戳**，只按知识点组织（OpenAI 兼容接口：智谱 / DeepSeek / Kimi / 通义） |
| **排版视图** | 整理稿不再是裸 Markdown：大节标题带**和正文序号一致的徽标**（正文写「一、」就是 ①，「知识框架 / 术语表」这类固定栏目改用主色竖条）、大节之间有一条细线分隔、三级标题的 `1.1` 单独用主色标出、点标题可折叠、要点是圆点列表、重点块是彩条卡片、术语表是斑马纹表格、顶部还有可跳转的目录；字号四档可调（0.9 / 1.0 / 1.15 / 1.3）。本地整理稿里的 `[03:12]` 是灰底时间戳胶囊（只是回头翻录播的索引；AI 整理稿会把时间戳擦掉）；**平板横过来自动分成左右两栏**：目录常驻左栏（200dp、字号收一档），正文铺满右边剩下的地方、一行不会横着排八十来个字，顶上那条状态和「重新 AI 整理一遍」整行收进工具栏 |
| **一键排版导出** | 一次导出两份：`.md`（整理稿 + 原始转写）和**排好版的 `.html`**（自带样式、支持深色、可直接打印成 PDF）。两份和 `shots/` 图片落在**同一个**「下载/同名文件夹/」里，打开一个文件夹就是全套；复制到剪贴板会同时带 HTML，粘进 Word / WPS 保留排版 |
| **悬浮截图按钮** | 屏幕上挂一个能随便拖动、松手自动贴边的圆钮，点一下就把当前画面截下来存进笔记 —— 看网课视频 / 直播 / PDF 时直接用；**「开始记录」就自动挂出来**（录屏授权和录音共用一次，不会多弹框），**记录一结束圆钮自己收回**，不会一直飘在界面上（设置里手动开的那个不受影响）；记录页上还有一排「课件截图」按钮；抓图瞬间圆钮自己藏起来，不会出现在图里；悬浮截图自己的那条通知上还有「截图」和「关闭」（录音那条通知上是「暂停 / 停止并保存」） |
| **截图 AI 分析（可选）** | 截完自动丢给视觉模型读懂课件、板书、图表，把定义 / 公式 / 表格 / 箭头关系写成要点存成这张图的说明（提示词明确要求「直接写图上内容、别用一张图展示了这种套话」；这段说明是**整理笔记的素材**，AI 整理时会把它并进对应小节的要点里）；默认用智谱 `glm-4v-flash`（**免费**）；没配 Key 也能截图，只是不带说明 |
| **截图进整理稿** | 截图会**插在对应的知识点旁边**：位置由 App 按截图时间算出来 —— 挑出时间上最贴近的那条要点，图就落在那句话下面；模型把时间戳删了也不要紧，再拿「这张图的说明 + 截图前后那半分钟的转写」跟正文比字面重合。本地整理和 AI 整理一条规矩，不会再一股脑堆到文末；AI 整理时**看图说明也算素材**，由模型整理进这一小节的要点，不再原样贴在图下面；只有图实在算不出落点时才退回末尾的「本课图示」兜底（AI 稿里整篇一个时间戳都没有、或本地提纲分不出小节时），一张都不会丢；导出的 HTML 把图片 base64 内嵌成单文件，导出的 Markdown 把 md 和 `shots/` 图片放进**同一个子目录**（相对路径才连得上图）；整理稿里的截图有宽度上限（竖屏 500dp、横屏 380dp，点开还是大图） |
| **整理稿不会过期** | 截图是录音中间插进来的，整理稿却是「生成那一刻的快照」：先看整理稿、之后才截图，磁盘上那份 md 里就根本没有图。现在笔记比整理稿新时，顶上会弹一条「有新内容」+「更新」：本地整理稿自己重做，AI 整理稿由你决定要不要再花一次 token |
| 手动打点 | 记录页「重点标记」按钮，随手插一个时间戳书签 |
| 内录系统声音 | **默认就走它**（Android 10+）：直接录系统播放的声音，比麦克风收外放干净得多；不想用（或系统太老）就在设置里换回麦克风 |
| **记录 / 笔记两块** | 主页**标题栏正中**一个滑块（`网课笔记 ◖记录│笔记◗`）：左边「记录」= 录下来的课（原始转写 + 截图），右边「笔记」= 整理好的整理稿。同一节课两边都在（原始转写永远留着），但**点开是两样东西**——「记录」点开是原始转写（顶上那颗「看整理稿」随时跳到笔记），「笔记」点开**直接**就是整理稿 |
| 笔记库 | 全文搜索（标题 + 转写）/ 统计行跟着页签换：「共 N 段记录 · 累计 2 小时 10 分」或「共 N 篇笔记」/ 「记录」那边还有「只看未整理」，一眼看出哪几段还没整理 / 长按或菜单进**多选**，一批一起 AI 整理 · 导出 · 删除 / 重命名 / 全文编辑（保留时间戳） |
| **删错了能捞回来** | 删除不是真删：笔记先进**回收站**，放满 7 天才会被自动清掉，这中间随时能反悔 —— 多选删完当场给一条「撤销」（8 秒）、详情页删完回到列表也有一条；菜单 →「回收站」是一整页列表，写着「几分钟前删除 · N 句」，点一下就放回去，每行「恢复」底下还有一颗红字「彻底删除」（想只扔一篇，不用先把整站清空），右上角还有「全部恢复 / 清空回收站」 |
| **自动取标题** | 停止记录时弹「保存笔记」：默认名字直接从这次记录的内容里取（不再是千篇一律的「网课笔记 11:15」），想改就在框里改；之后第一次 AI 整理会把名字换成这节课的**题目**（模型综合整堂课起的名字，像「Socket 的概念」这种），已经在详情页或保存框里自己改过的名字一个字都不会动 |
| **分享 / 导出** | 分享时可以挑 **纯文本 · Markdown 文件（.md）· 网页文件（.html）** 三种格式（网页版把图片内嵌成单文件，收的人打开就是排好版的一页，能直接打印成 PDF）；复制全文带富文本；一键导出 Markdown + 排版 HTML 到手机「下载」目录，详情页和整理稿页都是一次给两份 |
| 防丢 | 每识别出一句立刻追加落盘，进程被杀也只丢当前这一句 |
| 深色模式 | 跟随系统；字号可调（记录页三档 0.85 / 1.0 / 1.3，整理稿四档 0.9 / 1.0 / 1.15 / 1.3） |

## 怎么用

### 首页

标题栏正中一个滑块，分成两块：**记录**（录下来的课 —— 原始转写 + 截图）和**笔记**（整理好的整理稿）。
同一节课两边都能找到，点开却是两样东西：「记录」点开是原始转写，顶上一颗「看整理稿」随时跳过去；
「笔记」点开**直接**就是整理稿。统计行跟着滑块换（「共 13 段记录 · 累计 2 小时 40 分」/「共 10 篇笔记」），
「只看未整理」只在「记录」那边出现；搜索、多选两块通用。

### 记录

1. 首页「开始记录」→ 允许麦克风；Android 10 及以上**默认走内录系统声音**（更干净），所以还会过一次录屏授权 —— 不想内录就在设置里把「音频来源」换回麦克风。记录跑在**前台服务**里，息屏、切到别的 App 都不中断。
2. 听到重点点「重点标记」，插一个时间戳书签；「暂停」可以中途歇一下。
3. 「停止并保存」→ 弹出保存框，**标题已经按这次的内容自动起好了**（取自前几句里最有信息的字），想改就在框里改，懒得改直接保存；保存完**直接进整理稿页**，本地提纲已经在那儿等着了。
4. 每识别出一句就立刻落盘，进程被杀也只丢当前这一句。

### 整理与导出

1. 详情页**顶部那颗按钮**（或菜单）→「**整理成知识点笔记**」：先给一份**本地离线**提纲（分段 + 逐句打分挑要点 + 抽术语当小标题），秒出，不联网。已经有整理稿时按钮会变成「看整理稿」。
2. 想更成体系：整理稿页 →「**用 AI 体系化整理**」（可选）。整理稿有**排版视图**和 **Markdown 源码**两种模式：标题带序号徽标、可折叠，要点是圆点列表，`[03:12]` 是灰底时间戳胶囊，术语表是斑马纹表格，顶部有可跳转的目录，字号四档可调。**平板横过来会自动分成左右两栏**：目录（200dp）常驻左栏，正文铺满右边剩下的地方；顶上那条状态和「重新 AI 整理一遍」整行收进工具栏，横过来看着不再扁。
3. 导出：菜单 →「**导出到下载目录**」，一次给两份：
   - `.md`：整理稿 + 原始转写，和它的 `shots/` 图片一起放在「下载/同名文件夹」里，md 里引用的截图就在旁边；
   - `.html`：**排好版的网页版**，图片已经打包进这**一个文件**，双击就能在浏览器里看，直接「打印 → 存为 PDF」就是复习资料。
4. 菜单里的「复制整理稿」复制的是**富文本**，粘进 Word / WPS / 微信排版不会散。

> 想先看看排版长什么样、又不想真录一节课：设置页 →「**排版预览（示例笔记）**」。

### 截图（不用额外开）

1. 首页「开始记录」就行 —— 截图圆钮会**自动挂出来**，不需要再去设置里单独开一次。
   还没给过录屏授权的话，这一次会和「开始记录」并在一起要（内录本来就要它），
   所以整体只多这一个系统弹框；点了拒绝也不影响录音，只是少一个圆钮。
   （首次还要给一次「显示在其他应用上层」—— 记录页会问一次，点「去开启」跳过去打开，回来圆钮自己就挂上了。）
2. 圆钮可以拖到顺手的位置，松手自动贴边并记住位置。点圆钮 = 截图，
   点上方的 ✕ 或者通知栏的「关闭」= 收起。不想用悬浮窗、或者没给悬浮窗权限，
   记录页上那排「课件截图」按钮照样能截；不想用圆钮时，悬浮截图自己的通知上也有「截图」和「关闭」
   （录音那条通知上是「暂停 / 停止并保存」，两者是分开的两条）。
3. 截图会落到「正在记录的那篇笔记」（没在录音就落到当天的《课堂截图》），
   而且**记录页的列表里当场就能看到**（转写和截图按时间戳排在一起，点图看大图）；
   如果设置里开了「截图后自动用 AI 分析」而且填了 API Key，说明文字几秒后自动补上 ——
   中间**不弹任何「正在分析」的气泡**，写完直接出现在图下面。没开或者失败了也没关系：
   记录页和详情页的每张图下面都有「AI 分析这张图」，点一下重试。
4. 截图和录音**共用同一份录屏授权**（系统规定一个 App 同时只能有一个 MediaProjection，
   多要一次会把正在用的那个掐掉），所以两边可以同时开着互不影响，也不会多弹框。
5. 授权框里有一项**「共享或录制的范围」**，两种选法都对，看你要什么：
   - 想只录**网课视频那一块**（画面干净、不带状态栏）：选「单个应用」，再挑上网课的那个 App，
     比如哔哩哔哩 —— 声音照样内录得到（真机验过），不过**那个 App 得摆在屏幕上**，切走了就截不到图；
   - 不想挑、想全都收：选「整个屏幕」，不管你在哪个界面都截得到。
   有些 ROM（比如这台平板）每次都默认「单个应用」，那就顺手挑网课 App —— **别挑到「网课笔记」自己**，
   那样整节课 0 句、截到的也是笔记页。弹框之前 App 会提醒一句。

> 一个会让人意外的已知限制：录屏授权是**一次会话一次**的。手机重启、或者在系统状态栏点了
> 「停止录屏」之后，下次开始记录时重新授权一次就行 —— 录音和截图共用这一次授权，
> 所以只需重开一次，不会多弹框。

整理稿里截图会和文字**排在一起**，位置由 App 自己算、不问模型：能定位时按时间戳（哪条要点的时间离
截图最近，图就落在那条下面）；模型把时间戳全删了也不要紧 —— App 再拿「这张图的说明 + 截图前后那半分钟的
转写」跟正文逐行比字面重合，落到最像它的那一句下面，一个字都对不上时按时间落进大致对应的那一节。
「本课图示」只在图实在算不出落点时才兜底（本地提纲连一节都分不出、或整篇一个时间戳都没有），保证一张都不丢。

## 架构

```
AudioRecord(16k 单声道)
      │  麦克风 / AudioPlaybackCapture 内录
      ▼
Silero VAD（静音不产出片段 → 静音几乎不耗电）
      │  断句，最长 12 秒，静音 0.6 秒判定句子结束
      ▼
ArrayBlockingQueue(8)  ← 满了丢最旧的，宁可漏一句也不让延迟滚雪球
      ▼
单线程识别队列 → SenseVoice int8 离线识别
      ▼
文本清洗（去语气词 / 去复读 / 补句号）→ 关键词判定
      ▼
追加写 notes/<id>/lines.jsonl  →  通知栏 + 界面实时刷新
```

`Recorder` 是进程内单例，持有唯一状态源 `StateFlow<State>`；
`CaptureService` 只负责“别被系统杀掉”（前台服务 + 部分唤醒锁 + 通知栏开关）。

整理与排版链路（本地 / AI 两条路最后合流到同一套排版）：

```
lines.jsonl ─┬─ NoteDigest   本地提纲：时间 + 转折词 + 长度三重分段，逐句打分挑要点
             └─ LlmDigest    AI：≤ 2 万字单趟直出终稿；更长则「分段素材卡 → 全局提纲 → 逐节并行成文」
                              （跑在进程级 DigestJob 里：点完能退出页面，整理好一篇发一条通知、点开就是那篇；
                                一次只跑一篇，多选排队的自动接着来；接口地址自动补全、字段不认就重试、
                                网关报错自动换最小请求体）
                     │
                     ▼   digest.md
              MiniMarkdown.parse()   把 Markdown 拆成块（标题 / 要点 / 引用 / 表格 / 代码 / 关键词）
                     ├─ NoteRenderer    渲染成 V层：章节徽标、折叠、时间戳胶囊、彩条卡片、表格卡片、目录
                     └─ MiniMarkdown.toHtml   导出网页版（同一套块，两种输出）
```

## 技术栈

| 层 | 用了什么 |
|---|---|
| 语言 / 构建 | Kotlin 1.9.24、AGP 8.5.2、Gradle 8.9、compileSdk 34 / minSdk 24 / targetSdk 34、Java 17 |
| UI | 原生 View + ViewBinding（没有用 Compose）、Material Components、RecyclerView、ConstraintLayout，深色模式跟随系统 |

| 语音识别 | sherpa-onnx 1.13.8（官方预编译 AAR，放在 `app/libs/`）+ SenseVoice int8，全离线；断句用 Silero VAD v5 |
| 音频采集 | `AudioRecord`（麦克风）与 `MediaProjection` + `AudioPlaybackCapture`（内录系统声音），统一降采样到 16 kHz 单声道 |
| 截图 | `MediaProjection` + **常驻** `VirtualDisplay`/`ImageReader` 抓帧（一个录屏授权只建一次，之后每张图都复用它；最近一帧一直留在手里，所以画面停住也截得到；分辨率按像素总数封顶，长宽一起缩）；悬浮圆钮用 `WindowManager` + 前台服务 + 通知栏 |
| 存储 | 手机私有目录：`lines.jsonl` 逐句追加、截图存 `shots/*.jpg`、整理稿存 `digest.md`；导出走 `MediaStore` 落到系统「下载」 |
| 网络 | 只用 `HttpURLConnection` + `org.json`，没引任何 HTTP / JSON 第三方库；打的是 OpenAI 兼容的 `/chat/completions`（文本整理 + 多模态看图） |
| 排版 | 自研 `MiniMarkdown` 解析层 + 自研 `NoteRenderer`：同一套块结构同时渲染手机界面和导出 HTML，没有引 Markdown 库 |
| 测试 | JUnit 4 + Robolectric 4.12.2：本地整理算法、Markdown 解析、导出落盘，记录页的图文混排顺序，以及把排版视图真的测量 / 布局 / 绘制一遍的冒烟测试，共 176 条 |

## 隐私

- **语音识别 100% 在手机上完成**：sherpa-onnx + SenseVoice int8，不联网、不上传，录音只存在 App 私有目录。
- **AI 整理是可选的**：只有你自己点了「用 AI 体系化整理」，才会把那一篇的**文字**（不是录音）发给你自己填的服务商；不填 API Key 就完全离线。
- **截图默认只存在手机里**：只有开了「截图后自动用 AI 分析」并真的分析时，才会把**那张**压缩到长边 1280 的图发出去换说明，随时可以在设置里关掉。
- 网络请求只有上面两类，App 不会在后台偷偷联网。
- **笔记、截图、API Key 只留在这台手机上**：App 不参与云备份、也不参与换机迁移（`allowBackup=false` + `dataExtractionRules` 全排除），换台设备装完就是干净的，不会带出任何历史内容。
- 权限只用到：麦克风（`RECORD_AUDIO`）、录音与录屏的前台服务（`FOREGROUND_SERVICE*`）、
  悬浮窗（`SYSTEM_ALERT_WINDOW`，悬浮截图圆钮）、通知（`POST_NOTIFICATIONS`）、
  唤醒锁（WAKE_LOCK，息屏继续记）、音频设置（MODIFY_AUDIO_SETTINGS，内录系统声音要用）、
  网络（INTERNET，只在你点「AI 整理」「AI 分析这张图」时用）。

隐私相关的设置、数据存在哪、什么情况下会联网、权限都用在哪、怎么自己核对代码，见 [**PRIVACY.md**](PRIVACY.md)。

## 已知限制

- 内录依赖 App 自身允许被录制；部分网课 App 会关掉这个开关，此时只能改用麦克风。
- SenseVoice 是通用中文模型，专业术语（人名、公式、英文缩写）会有误差，重点内容建议回看录像。
- 长讲座建议插着电使用；识别本身有 VAD 门控，但屏幕和麦克风持续工作仍有耗电。
- 安装包约 286 MB，其中 228 MB 是内置的识别模型（占八成），其余是原生库和代码。
  模型直接读 APK 里的资源、原生库也不解压到内部存储，所以装完之后不会再额外占一份空间。
- AI 整理要联网、要花 token：报错时会尽量自动降级重试；如果提示里出现 `tool_calls`，
  通常是「模型名/中转站不是普通对话模型」，换成 `deepseek-chat`、`glm-4-flash` 这类即可。
- 授权框里的「共享或录制的范围」二选一都行，关键是**别挑错 App**：选「单个应用」只会录到你挑的
  那一个应用 —— 挑上网课 App（比如哔哩哔哩）时截图最干净（真机验过：声音也照样内录得到），
  但它**必须正显示在屏幕上**，你切到别的 App 之后那段时间就截不到图（系统不再推帧，气泡会提示
  「这张没截到」）；挑成「网课笔记」自己则会整节课 0 句、截图是自家页面。想省心就选「整个屏幕」，
  任何界面都截得到。
- 截图需要「悬浮窗 + 录屏」两道系统授权，而且录屏授权是**一次会话一次**的：
  手机重启、系统回收、或你在状态栏点了「停止」之后，下一次开始记录时会重新要一次。
  好在它已经并进「开始记录」这一步，不用专门回设置里开，也不会多弹框。
- 录音（内录）和截图共用同一个录屏授权，任何一边停止都不会掐断另一边；
  授权本身仍然是「一次会话一次」，要等两边都退出了才真正结束。
- AI 整理是后台任务：整理期间退出页面、切到别的 App 都不会中断；但如果**把 App 从最近任务里划掉**
  （或在系统里强制停止），进程没了整理也就停了，这时回整理稿页再点一次就行。跑着的时候通知栏只有一条
  「AI 正在整理」：写着当前这篇，多选时还有「还剩 N 篇」和一条进度条，上面挂着一颗「**取消生成**」，
  想掐断不用回 App。**整理好一篇就单独发一条**「整理好了 ·《这节课》」，点开就是那篇 —— 人翻到那篇
  整理稿它自己也会消失，不用手动划掉。万一进程被系统在后台杀掉了，那条进度通知会在**下次打开 App 时
  自动消失**，不会留一条永远转不完的进度在通知栏里。
- 视觉模型默认 `glm-4v-flash` 是智谱的**免费**模型（不限金额，但有并发 / 频率限制），
  被限流会返回 429，App 会自动退避重试。免费档的上下文不大，所以截图会先压到长边 1280 再发；
  想要更细的解读可以换成同样免费的 `glm-4.6v-flash`（上下文更大）。
- 部分网课 App 会禁止被录制（`FLAG_SECURE`），这类画面截出来是黑图，属于系统限制，无解。

## 实现上几个值得说的地方

起点是 sherpa-onnx 官方 Demo（见文末致谢）。下面这些是从那之后攒下来的、
光看功能清单看不出来的东西，讲的是「为什么这么做」。

### 记录与识别

- 进程里只有一个 `Recorder` 单例持有状态（`StateFlow<State>`），`CaptureService` 只负责别被系统杀掉
  （前台服务 + 部分唤醒锁 + 通知栏开关），所以息屏、切到别的 App、转屏都不会中断。
- 识别是**单线程串行队列**：上游 Demo 每段 `launch` 一个协程，顺序和并发数都不可控；
  这里音频线程 → `ArrayBlockingQueue(8)`（满了丢最旧的，宁可漏一句也不让延迟滚雪球）→ 单线程识别。
- VAD 按长讲座调过：静音 0.6 秒判定句子结束、单句最长 12 秒；模型常驻，启动时拿一段 0.6 秒静音预热，
  免得第一句明显变慢；识别线程数 1–4 可调。
- 文本清洗（`TextPolish`）做去语气词、去 ASR 复读、补标点，再按关键词标星
  （重点 / 考点 / 必考 / 记住 / 注意 / 关键 / 核心 / 公式 / 定理 / 定义…）。
- 内录走 `MediaProjection` + `AudioPlaybackCapture`，48k → 16k 三点均值降采样，
  和麦克风统一成 16k 单声道，后面整条链路只认一种格式。

### 本地整理（`NoteDigest`，离线）

- 时间 + 转折词 + 长度三重分段；逐句打分挑要点（术语密度、定义与因果信号、数字加分，口语铺垫扣分），
  定义句、作业、公式类内容强制保留，不会被分数挤掉。
- 术语抽取用**左右邻接熵** —— 中文没有分词器时，字符串切分很容易把「储结构」「中序遍」这种半个词抽出来，
  邻接熵能把这些边界找回来。

### AI 整理（`LlmDigest`，可选）

- ≤ 2 万字的课**一趟直出**终稿；更长才走「分段素材卡 → 全局提纲 → 逐节并行成文」，
  每节带自己那一段素材和篇幅预算，两小时的课也不会被摊薄成骨架；单节失败拿提纲里的写法顶上，
  不让整篇失败。素材卡并行发出（最多 6 个同时），完成顺序乱了也不影响结果。
- 提示词按「**不看录播、只听这份笔记也能学会**」来写：每个知识点说清是什么 / 为什么 / 怎么用 / 哪里容易错，
  而不是把老师的话压缩一遍；栏目随内容走 —— 没有作业就不写作业那一节，空壳小节比缺一节更糟。
- **成稿不带时间戳**：`[mm:ss]` 只是 App 定位截图用的坐标，插完图就擦掉（`stripTimestamps`），
  成品只按知识点组织、不是一串时刻表。
- 接口层自愈：地址少了 `/v1` 自动补全，服务商不认 `temperature` / `max_tokens` 就去掉重试，
  网关把请求当成「带 tool_calls 的会话」返回报错时退化成最小请求体再试一次，429 / 5xx 退避重试，
  实在不行给一句人话而不是把原始报错甩出来。
- 模型不听话时的兜底全在 App 这边，都是确定性的字符串处理：整篇被 ``` 包住自动拆开
  （不拆的话排版视图会把整篇当代码块渲染）、`- ```bash` 还原成真代码块、
  `_旁注_` / `*旁注*` 认成斜体、只剩记号的 `- >` 不再渲染成空引用框。

### 排版与导出

- `MiniMarkdown` 把整理稿解析成块，`NoteRenderer` 画成界面，`MiniMarkdown.toHtml` 出网页版 ——
  同一套块两种输出，所以界面和导出的网页长得一样，也方便单测。
- 章节徽标跟着正文序号（正文写「一、」就是 ①，「知识框架 / 术语表」这类固定栏目改用主色竖条）、
  大节之间细线分隔、点标题可折叠、术语表是斑马纹表格、顶部有可跳转目录、字号四档。
- 导出的 `.md`、`.html` 和 `shots/` 落在**同一个**「下载/同名文件夹/」里，打开一个文件夹就是全套；
  网页版把图片 base64 内嵌成单文件，双击就能看、直接打印成 PDF；复制到剪贴板会同时写 HTML，
  粘进 Word / WPS 不掉排版。
- 分享给三种格式（纯文本 / `.md` / `.html`），弹的是 App 自己拼的面板 —— 有些 ROM 会把系统
  `setItems` 的列表挤成 0 高，三个选项一个都看不见。

### 截图

- 一个录屏授权只建一次「镜子」（`VirtualDisplay` + `ImageReader`，由 `MirrorSlot` 守着）。
  Android 14 起同一个授权第二次 `createVirtualDisplay` 会被系统抛异常并**顺手停掉整个授权**，
  表现就是「点第二下截图，录制没了」。
- 建镜子必须**先装 `setOnImageAvailableListener`、再 `createVirtualDisplay`**：写反了首帧会赶在监听装好之前
  进队列，队列一满（`MAX_IMAGES = 3`）系统就不再推帧，表现是「屏幕明明亮着，却一帧都等不到」。
- 最近那一帧一直攥在手里（`FrameSlot`），所以视频暂停、课件页停住也截得到；镜子分辨率按**像素总数封顶**，
  长宽一起缩、不变形、只降不升，合成 / 解码 / 压缩都跟着快一截。
- 截图和录音**共用同一份录屏授权**（`ProjectionBook` 记账：最后一个走的才真正停），
  所以内录时点圆钮不用再弹一次授权框，连点截图也不会把录制弄断。
- 图落在哪由 **App 算、不问模型**：先按时间戳找最近的那条要点；模型把时间戳删了也不要紧，
  再拿「这张图的说明 + 截图前后那半分钟的转写」跟正文逐行比字面重合。标题行、表格、代码块不当落点，
  免得图卡在标题和正文之间、或者把表格拦腰截断。
- 悬浮圆钮能拖、松手贴边、记住位置；「开始记录」时自动挂出来，记录一结束自己收回，
  抓图那一瞬间自己藏起来（不会出现在图里）。

### 笔记库与通知

- 删除是**挪进回收站**（`notes/.trash/<id>`），放满 7 天才真清（`purgeTrash`，进程起来时扫一次）；
  多选删完给一条能点的「撤销」（8 秒），回收站页可以单篇恢复 / 彻底删除 / 全部恢复 / 清空。
- AI 整理跑在**进程级后台任务**（`DigestJob`）里：点完就能退出页面。跑着的时候通知栏只有一条安静的进度
  （多选时带「还剩 N 篇 / 第 i/N 篇」和进度条 + 一颗「取消生成」），**每整理好一篇单独发一条**，
  点开就是那篇；打开那篇整理稿，它那条通知自己消失；进程被后台杀掉留下的假通知，下次打开 App 时清掉。
- 所有对 `lines.jsonl` 的「读 → 改 → 写」都串行化：截图和它的 AI 说明是录音过程中插进来的，
  没有这把锁就可能盖掉刚识别出的一句话。

### 工程化

- 签名打包 + 模型直接内置进 APK（`onnx` / `txt` 走 `noCompress`），装完就能离线用；
  模型直接读 APK 里的资源、原生库也不解压到内部存储，所以装完不会再额外占一份空间。

# 网课笔记 · Online-Class-Notes

**把网课里老师讲的话，自动变成一份带时间戳、能排版、能导出的文字笔记。**

录音 → 本地离线识别 → 实时转写 → 一键整理成提纲（可选接大模型写成体系化终稿）→ 排好版导出 Markdown / HTML。
看网课视频时挂一个悬浮圆钮随时截屏，截图自动交给视觉模型读懂，直接写进笔记。

> **语音识别全程离线**：不联网、不上传，录音只存在手机私有目录里。
> 只有你主动点「AI 整理」或「AI 分析这张图」时，才会把**文字**或**那一张图**发给你自己配置的服务商；不填 API Key 就完全离线。

## 功能

| 功能 | 说明 |
|---|---|
| 一键记录 | 首页大按钮开始，前台服务运行，息屏 / 切到别的 App 都能继续记 |
| 实时转写 | VAD 自动断句 + SenseVoice 中文识别，每句话带 `[分:秒]` 时间戳 |
| 自动标重点 | 听到「重点 / 必考 / 注意 / 记住 / 考试」等词自动标星高亮 |
| **知识点笔记** | 一键把整段转写**整理成提纲**：自动分节、提炼要点、抽术语当小标题，全程本地离线，秒出结果 |
| **AI 体系化整理（可选）** | 接大模型把整堂课编辑成一份成体系的终稿：知识框架 → 大节 / 小节 → 术语公式表 → 易错点 → 一句话总结 → 作业。提示词按「**不看录播、只听这份笔记也能学会**」来写：每个知识点都要说清是什么 / 为什么 / 怎么用 / 哪里容易错，而不是把老师的话压缩一遍；长课自动分段并行整理再合并（OpenAI 兼容接口：智谱 / DeepSeek / Kimi / 通义） |
| **排版视图** | 整理稿不再是裸 Markdown：大节标题带**和正文序号一致的徽标**（正文写「一、」就是 ①，不再按出现顺序硬编号，「知识框架 / 术语表」这类固定栏目改用主色竖条）、大节之间有一条细线分隔，三级标题的 `1.1` 单独用主色标出，点标题可折叠，要点是圆点列表，`[03:12]` 弱化成灰色时间戳胶囊（回头翻录播用的索引，不该抢知识点的注意力），重点块是彩条卡片，术语表是斑马纹表格，顶部还有可跳转的目录；字号三档可调 |
| **一键排版导出** | 一次导出两份：`.md`（整理稿 + 原始转写）和**排好版的 `.html`**（自带样式、支持深色、可直接打印成 PDF）。两份和 `shots/` 图片落在**同一个**「下载/同名文件夹/」里，打开一个文件夹就是全套；复制到剪贴板会同时带 HTML，粘进 Word / WPS 保留排版 |
| **悬浮截图按钮** | 屏幕上挂一个能随便拖动、松手自动贴边的圆钮，点一下就把当前画面截下来存进笔记 —— 看网课视频 / 直播 / PDF 时直接用；**「开始记录」就自动挂出来**，不用再去设置里单独开（录屏授权和录音共用一次，不会多弹框），**记录一结束圆钮自己收回**，不会一直飘在界面上（设置里手动开的那个不受影响）；记录页上还有一排「课件截图」按钮；抓图瞬间圆钮自己藏起来，不会出现在图里；通知栏也有「截图」按钮 |
| **截图 AI 分析（可选）** | 截完自动丢给视觉模型读懂课件、板书、图表，把定义 / 公式 / 表格 / 箭头关系写成要点存成这张图的说明；默认用智谱 `glm-4v-flash`（**免费**）；没配 Key 也能截图，只是不带说明 |
| **截图进整理稿** | 截图会**插在对应的知识点旁边**：本地整理按时间戳归进当时那个小节，AI 整理则由模型自己挑位置，漏放的图自动补到末尾的「本课图示」，一张都不会丢；导出的 HTML 把图片 base64 内嵌成单文件，导出的 Markdown 把 md 和 `shots/` 图片放进**同一个子目录**（相对路径才连得上图） |
| **整理稿不会过期** | 截图是录音中间插进来的，整理稿却是「生成那一刻的快照」：先看整理稿、之后才截图，磁盘上那份 md 里就根本没有图（这正是「图示是空的」的真凶）。现在笔记比整理稿新时，顶上会弹一条「有新内容」+「更新」：本地整理稿自己重做，AI 整理稿由你决定要不要再花一次 token |
| **AI 在后台整理** | 点完「用 AI 体系化整理」就可以退出页面去干别的：一整堂课要几十秒到一两分钟，这段时间交给**进程级后台任务**，状态栏挂一条安静的进度，**整理好发通知**，点通知直接看成品。页面上只显示「第 x/y 段」，绝不把模型半生不熟的中间文字刷给你看 |
| 手动打点 | 记录页「重点标记」按钮，随手插一个时间戳书签 |
| 内录系统声音 | Android 10+ 可录系统播放的声音（比麦克风收录外放干净得多） |
| 笔记库 | 打开 App 就是笔记列表（搜索框下面一行写着「我的笔记 · 共 N 篇 · 累计 2 小时 10 分」）/ 全文搜索 / 右边「只看未整理」一键筛出还没整理的 / 长按或菜单进**多选**，一批一起 AI 整理 · 导出 · 删除 / 重命名 / 全文编辑（保留时间戳） |
| **删错了能捞回来** | 删除不是真删：笔记先进**回收站**，放满 7 天才会被自动清掉，这中间随时能反悔 —— 多选删完当场给一条「撤销」（8 秒）、详情页删完回到列表也有一条；菜单 →「回收站」是一整页列表，写着「几分钟前删的 · N 句」，点一下就放回去，右上角还有「全部恢复 / 清空回收站」 |
| **自动取标题** | 停止记录时弹「保存笔记」：默认名字直接从这次记录的内容里取（不再是千篇一律的「网课笔记 11:15」），想改就在框里改 |
| 导出分享 | 复制全文（含富文本）、分享、一键导出 Markdown + 排版 HTML 到手机「下载」目录；详情页和整理稿页都是一次给两份 |
| 防丢 | 每识别出一句立刻追加落盘，进程被杀也只丢当前这一句 |
| 深色模式 | 跟随系统；记录页支持三档字号 |

## 怎么用

### 记录

1. 首页「开始记录」→ 允许麦克风（要用内录还得过一次录屏授权）。记录跑在**前台服务**里，息屏、切到别的 App 都不中断。
2. 听到重点点「重点标记」，插一个时间戳书签；「暂停」可以中途歇一下。
3. 「停止并保存」→ 弹出保存框，**标题已经按这次的内容自动起好了**（取自前几句里最有信息的字），想改就在框里改，懒得改直接保存；保存完**直接进整理稿页**，本地提纲已经在那儿等着了。
4. 每识别出一句就立刻落盘，进程被杀也只丢当前这一句。

### 整理与导出

1. 详情页**顶部那颗按钮**（或菜单）→「**整理成知识点笔记**」：先给一份**本地离线**提纲（分段 + 逐句打分挑要点 + 抽术语当小标题），秒出，不联网。已经有整理稿时按钮会变成「看整理稿」。
2. 想更成体系：整理稿页 →「**用 AI 体系化整理**」（可选）。整理稿有**排版视图**和 **Markdown 源码**两种模式：标题带序号徽标、可折叠，要点是圆点列表，`[03:12]` 是彩色时间戳胶囊，术语表是斑马纹表格，顶部有可跳转的目录，字号四档可调。
3. 导出：菜单 →「**导出到下载目录**」，一次给两份：
   - `.md`：整理稿 + 原始转写，和它的 `shots/` 图片一起放在「下载/同名文件夹」里，md 里引用的截图就在旁边；
   - `.html`：**排好版的网页版**，图片已经打包进这**一个文件**，双击就能在浏览器里看，直接「打印 → 存为 PDF」就是复习资料。
4. 菜单里的「复制整理稿」复制的是**富文本**，粘进 Word / WPS / 微信排版不会散。

> 想先看看排版长什么样、又不想真录一节课：设置页 →「**排版预览（示例笔记）**」。

### 截图（不用额外开）

1. 首页「开始记录」就行 —— 截图圆钮会**自动挂出来**，不需要再去设置里单独开一次。
   还没给过录屏授权的话，这一次会和「开始记录」并在一起要（内录本来就要它），
   所以整体只多这一个系统弹框；点了拒绝也不影响录音，只是少一个圆钮。
   （首次还要给一次「显示在其他应用上层」—— 记录页会问一次，点「去开启」跳过去打开，回来圆钮自己就挂上了。）
2. 圆钮可以拖到顺手的位置，松手自动贴边并记住位置。点圆钮 = 截图，
   点上方的 ✕ 或者通知栏的「关闭」= 收起。不想用悬浮窗、或者没给悬浮窗权限，
   记录页上那排「课件截图」按钮照样能截。通知栏也能直接截图。
3. 截图会落到「正在记录的那篇笔记」（没在录音就落到当天的《课堂截图》），
   而且**记录页的列表里当场就能看到**（转写和截图按时间戳排在一起，点图看大图）；
   如果设置里开了「截图后自动用 AI 分析」而且填了 API Key，说明文字几秒后自动补上 ——
   中间**不弹任何「正在分析」的气泡**，写完直接出现在图下面。没开或者失败了也没关系：
   记录页和详情页的每张图下面都有「AI 分析这张图」，点一下重试。
4. 截图和录音**共用同一份录屏授权**（系统规定一个 App 同时只能有一个 MediaProjection，
   多要一次会把正在用的那个掐掉），所以两边可以同时开着互不影响，也不会多弹框。
5. 授权框里有一项**「共享或录制的范围」**，两种选法都对，看你要什么：
   - 想只录**网课视频那一块**（画面干净、不带状态栏）：选「单个应用」，再挑上网课的那个 App，
     比如哔哩哔哩 —— 声音照样内录得到（真机验过），不过**那个 App 得摆在屏幕上**，切走了就截不到图；
   - 不想挑、想全都收：选「整个屏幕」，不管你在哪个界面都截得到。
   有些 ROM（比如这台平板）每次都默认「单个应用」，那就顺手挑网课 App —— **别挑到「网课笔记」自己**，
   那样整节课 0 句、截到的也是笔记页。弹框之前 App 会提醒一句。

> 一个会让人意外的已知限制：录屏授权是**一次会话一次**的。手机重启、或者在系统状态栏点了
> 「停止录屏」之后，下次开始记录时重新授权一次就行 —— 录音和截图共用这一次授权，
> 所以只需重开一次，不会多弹框。

整理稿里截图会和文字**排在一起**：本地整理按时间戳插进它当时所在的小节，AI 整理则由模型决定放哪；「本课图示」只兜底收那些没被放进去的图，保证一张都不丢。

## 架构

```
AudioRecord(16k 单声道)
      │  麦克风 / AudioPlaybackCapture 内录
      ▼
Silero VAD（静音不产出片段 → 静音几乎不耗电）
      │  断句，最长 12 秒，静音 0.6 秒判定句子结束
      ▼
ArrayBlockingQueue(8)  ← 满了丢最旧的，宁可漏一句也不让延迟滚雪球
      ▼
单线程识别队列 → SenseVoice int8 离线识别
      ▼
文本清洗（去语气词 / 去复读 / 补句号）→ 关键词判定
      ▼
追加写 notes/<id>/lines.jsonl  →  通知栏 + 界面实时刷新
```

`Recorder` 是进程内单例，持有唯一状态源 `StateFlow<State>`；
`CaptureService` 只负责“别被系统杀掉”（前台服务 + 部分唤醒锁 + 通知栏开关）。

整理与排版链路（本地 / AI 两条路最后合流到同一套排版）：

```
lines.jsonl ─┬─ NoteDigest   本地提纲：时间 + 转折词 + 长度三重分段，逐句打分挑要点
             └─ LlmDigest    AI：单趟 ≤ 2 万字直接出终稿，更长才切段并行出素材卡再合并
                              （跑在进程级 DigestJob 里：点完能退出页面，整理完发通知；
                                接口地址自动补全、字段不认就重试、网关报错自动换最小请求体）
                     │
                     ▼   digest.md
              MiniMarkdown.parse()   把 Markdown 拆成块（标题 / 要点 / 引用 / 表格 / 代码 / 关键词）
                     ├─ NoteRenderer    渲染成 V层：章节徽标、折叠、时间戳胶囊、彩条卡片、表格卡片、目录
                     └─ MiniMarkdown.toHtml   导出网页版（同一套块，两种输出）
```

## 技术栈

| 层 | 用了什么 |
|---|---|
| 语言 / 构建 | Kotlin 1.9.24、AGP 8.5.2、Gradle 8.9、compileSdk 34 / minSdk 24 / targetSdk 34、Java 17 |
| UI | 原生 View + ViewBinding（没有用 Compose）、Material Components、RecyclerView、ConstraintLayout，深色模式跟随系统 |
| 异步 | Kotlin 协程 + `StateFlow` 单一状态源；采集线程 → `ArrayBlockingQueue(8)` → 单线程识别队列 |
| 语音识别 | sherpa-onnx 1.13.8（官方预编译 AAR，放在 `app/libs/`）+ SenseVoice int8，全离线；断句用 Silero VAD v5 |
| 音频采集 | `AudioRecord`（麦克风）与 `MediaProjection` + `AudioPlaybackCapture`（内录系统声音），统一降采样到 16 kHz 单声道 |
| 截图 | `MediaProjection` + **常驻** `VirtualDisplay`/`ImageReader` 抓帧（一个录屏授权只建一次，之后每张图都复用它；最近一帧一直留在手里，所以画面停住也截得到；分辨率按像素总数封顶，长宽一起缩）；悬浮圆钮用 `WindowManager` + 前台服务 + 通知栏 |
| 存储 | 手机私有目录：`lines.jsonl` 逐句追加、截图存 `shots/*.jpg`、整理稿存 `digest.md`；导出走 `MediaStore` 落到系统「下载」 |
| 网络 | 只用 `HttpURLConnection` + `org.json`，没引任何 HTTP / JSON 第三方库；打的是 OpenAI 兼容的 `/chat/completions`（文本整理 + 多模态看图） |
| 排版 | 自研 `MiniMarkdown` 解析层 + 自研 `NoteRenderer`：同一套块结构同时渲染手机界面和导出 HTML，没有引 Markdown 库 |
| 测试 | JUnit 4 + Robolectric 4.12：本地整理算法、Markdown 解析、导出落盘，记录页的图文混排顺序，以及把排版视图真的测量 / 布局 / 绘制一遍的冒烟测试，共 122 条 |

## 隐私

- **语音识别 100% 在手机上完成**：sherpa-onnx + SenseVoice int8，不联网、不上传，录音只存在 App 私有目录。
- **AI 整理是可选的**：只有你自己点了「用 AI 体系化整理」，才会把那一篇的**文字**（不是录音）发给你自己填的服务商；不填 API Key 就完全离线。
- **截图默认只存在手机里**：只有开了「截图后自动用 AI 分析」并真的分析时，才会把**那张**压缩到长边 1280 的图发出去换说明，随时可以在设置里关掉。
- 网络请求只有上面两类，App 不会在后台偷偷联网。
- **笔记、截图、API Key 只留在这台手机上**：App 不参与云备份、也不参与换机迁移（`allowBackup=false` + `dataExtractionRules` 全排除），换台设备装完就是干净的，不会带出任何历史内容。
- 权限只用到：麦克风、录音（内录）、悬浮窗（悬浮截图圆钮）、通知（前台服务）。

隐私相关的设置、数据存在哪、什么情况下会联网、权限都用在哪、怎么自己核对代码，见 [**PRIVACY.md**](PRIVACY.md)。

## 已知限制

- 内录依赖 App 自身允许被录制；部分网课 App 会关掉这个开关，此时只能改用麦克风。
- SenseVoice 是通用中文模型，专业术语（人名、公式、英文缩写）会有误差，重点内容建议回看录像。
- 长讲座建议插着电使用；识别本身有 VAD 门控，但屏幕和麦克风持续工作仍有耗电。
- 安装包约 286 MB，其中 229 MB 是内置的识别模型（占八成），其余是原生库和代码。
  模型直接读 APK 里的资源、原生库也不解压到内部存储，所以装完之后不会再额外占一份空间。
- AI 整理要联网、要花 token：报错时会尽量自动降级重试；如果提示里出现 `tool_calls`，
  通常是「模型名/中转站不是普通对话模型」，换成 `deepseek-chat`、`glm-4-flash` 这类即可。
- 授权框里的「共享或录制的范围」二选一都行，关键是**别挑错 App**：选「单个应用」只会录到你挑的
  那一个应用 —— 挑上网课 App（比如哔哩哔哩）时截图最干净（真机验过：声音也照样内录得到），
  但它**必须正显示在屏幕上**，你切到别的 App 之后那段时间就截不到图（系统不再推帧，气泡会提示
  「这张没截到」）；挑成「网课笔记」自己则会整节课 0 句、截图是自家页面。想省心就选「整个屏幕」，
  任何界面都截得到。
- 截图需要「悬浮窗 + 录屏」两道系统授权，而且录屏授权是**一次会话一次**的：
  手机重启、系统回收、或你在状态栏点了「停止」之后，下一次开始记录时会重新要一次。
  好在它已经并进「开始记录」这一步，不用专门回设置里开，也不会多弹框。
- 录音（内录）和截图共用同一个录屏授权，任何一边停止都不会掐断另一边；
  授权本身仍然是「一次会话一次」，要等两边都退出了才真正结束。
- AI 整理是后台任务：整理期间退出页面、切到别的 App 都不会中断；但如果**把 App 从最近任务里划掉**
  （或在系统里强制停止），进程没了整理也就停了，这时回整理稿页再点一次就行。
- 视觉模型默认 `glm-4v-flash` 是智谱的**免费**模型（不限金额，但有并发 / 频率限制），
  被限流会返回 429，App 会自动退避重试。它上下文只有 4K，所以截图会先压到长边 1280 再发；
  想要更细的解读可以换成同样免费的 `glm-4.6v-flash`（上下文更大）。
- 部分网课 App 会禁止被录制（`FLAG_SECURE`），这类画面截出来是黑图，属于系统限制，无解。

## 相比上游 Demo 改了什么

1. 从 Activity 内的一次性录音，改成**前台服务 + 单例状态机**，支持息屏、后台、暂停/继续。
2. 识别结果从 TextView 拼接，改成**带时间戳的笔记条目**，逐句追加落盘（JSONL）。
3. 新增**笔记数据层**（NoteStore）：列表、全文搜索、编辑、重命名、删除、Markdown 导出。
4. 新增**内录系统声音**（MediaProjection + AudioPlaybackCapture，48k→16k 三点均值降采样）。
5. 新增**文本清洗与重点识别**（TextPolish）：去语气词、去 ASR 复读、补标点、关键词标星。
6. 性能改造：识别改为**单线程串行队列**（原 Demo 每段 `launch` 一个协程，顺序和线程数都不可控）、
   VAD 参数针对长讲座调优、模型常驻 + 静音预热、线程数可调（1–4）。
7. 工程化：签名打包 + 模型直接内置进 APK —— 装完就能离线用，不需要联网下模型。
8. 新增**知识点笔记整理引擎**（`NoteDigest`）：时间 + 转折词 + 长度三重分段，
   逐句打分（术语密度 / 定义与因果信号 / 数字 / 口语铺垫扣分）挑要点，
   再用**左右邻接熵**抽术语（专门解决中文没有分词器时把「储结构」「中序遍」这种半个词抽出来的问题）。
   定义句、作业、公式类内容强制保留，不会被分数挤掉。
9. 新增**可选的大模型整理**（`LlmDigest`）：长转写按 2600 字切块逐段整理再合并，进度实时回显；
   没配 API Key 时整条链路完全不联网。
10. 整理稿存档到 `notes/<id>/digest.md`，导出 / 分享时自动放在正文最前面，原始转写附在后面。
11. 新增**排版引擎**（`MiniMarkdown` + `NoteRenderer`）：整理稿的 Markdown 先解析成块，
    再由渲染器画成排版好的一页 —— 章节序号徽标、小节可折叠、要点圆点、`[mm:ss]` 时间戳胶囊、
    行内代码胶囊、提示块彩条卡片、斑马纹表格、关键词胶囊、可跳转目录、字号三档。
    解析层是纯 Kotlin，条链路（界面 / 导出 HTML）共用，也方便单测。
12. 新增**排版版 HTML 导出**与**富文本复制**：导出同时给 `.md` 和自带样式的 `.html`
    （支持深色模式、可直接打印成 PDF）；复制到剪贴板会同时写入 HTML，粘进 Word / WPS 不掉排版。
13. AI 整理升级为**体系化终稿**：长课按 2600 字切段先出素材卡，再合成一份带知识框架、
    术语公式表、易错点、一句话总结、作业预告的完整笔记；接口层做了自愈 —— 地址少了 `/v1`
    自动补全、404 自动换拼法、服务商不认 `temperature` / `max_tokens` 就去掉重试、
    网关把请求当成「带 tool_calls 的会话」返回报错时自动退化成最小请求体再试一次，
    429 / 5xx / 网络抖动会退避重试，实在不行也会给出人话提示而不是把原始报错甩出来。
14. 测试：除了本地整理算法，还会用 Robolectric 把整理稿真的渲染一遍
    （走一遍测量 / 布局 / 绘制），防止排版代码一开就崩；设置页新增「排版预览」，不用录音也能看排版。
15. 新增**悬浮截图**（`ShotService` + `ShotGate`）：一个能拖动、贴边、记位置的悬浮圆钮，
    点一下就把当前屏幕截进笔记。截屏走 `MediaProjection` + `VirtualDisplay` + `ImageReader` 抓单帧，
    和内录音频**共用同一份录屏授权**（内录时点圆钮不用再弹授权框）；
    后台是前台服务 + 通知栏「截图 / 关闭」，不用时会自己把悬浮窗拆干净。
16. 新增**图片条目**：`Entry` 多出 `image` / `caption` / `analyzed` 三个字段（旧笔记文件照样能读），
    截图按时间戳混在转写文字里，详情页是「缩略图 + 说明 + AI 分析按钮」，点开有独立的看大图页
    （双指缩放、拖动、双击复位、编辑说明、复制、分享、删除）。
17. 新增**视觉模型分析**（`LlmDigest.analyzeImage`）：图片压到长边 1280 再转 base64，
    按 OpenAI 兼容的多模态格式（`content` 数组 + `image_url`）发出去，换模型只改一个输入框；
    默认 `glm-4v-flash`（智谱免费视觉模型）。
18. 整理稿打通图片：截图按时间戳**插进它所在的小节**（本地整理按小节的起止时间归位，
    AI 整理则把 `[[IMGn]]` 记号交给模型挑位置、再由 App 还原成 `![…](shots/x.jpg)`，
    模型漏放的图兜底收进末尾的「本课图示」）；`MiniMarkdown` 新增 `Block.Image`，
    `NoteRenderer` 画成圆角卡片（点一下放大）；
    导出 HTML 时把图片内嵌成 base64 单文件，导出 Markdown 时把 md 和 `shots/` 图一起放进同名子目录。
19. 存储并发加固：所有对 `lines.jsonl` 的「读 → 改 → 写」串行化。
    截图是录音过程中插进来的，AI 分析完还要回写说明，没有这把锁就可能把刚识别出的一句话盖掉。
20. 导出链路修了三处（`NoteStore.exportAll`）：MediaStore 的 MIME 从 `text/plain` 换成 `text/markdown`
    （否则文件会被系统存成 `.md.txt`）；Markdown 和它的 `shots/` 图放进同一个子目录
    （否则 md 里的 `![图示](shots/x.jpg)` 连不上图）；详情页也跟整理稿页一样一次导出 md + HTML。
21. `MiniMarkdown` 新增行内 `Span.Image`：截图夹在要点行中间时（没整理稿、导原始转写就是这种形状），
    导出的 HTML 会渲染成真正的图片标签，不再把内嵌的 base64 当纯文本吐出来。
22. 整理稿**不再过期**：截图是录音中间插进来的，而 `digest.md` 是「生成那一刻的快照」——
    先看整理稿、之后才截图，磁盘上那份 md 里就根本没有图。这正是「图示还是空的」的真凶。
    现在 `NoteStore.digestStale()` 用文件时间比出「笔记比整理稿新」，页面上弹一条「有新内容 + 更新」：
    本地整理稿自动重做，AI 整理稿留给用户决定；顺带修掉图片基准目录算错的路径问题
    （`NoteRenderer.resolveImage` + `imageDir = NoteStore.noteDir(id)`，两种路径约定都认）。
23. AI 整理改成**进程级后台任务**（`DigestJob`）：进度 / 结果 / 失败都挂在进程上而不是页面上，
    点完就能退出；状态栏一条安静的通知（`CHANNEL_DIGEST`），跑完发带内容的通知、点开即看；
    页面只显示「第 x/y 段」这种干净状态，模型半成品的文字不再流式刷给用户。
    顺带补上 Android 13+ 的通知权限申请 —— 以前只在缺麦克风权限时顺带要，
    老用户升级上来永远等不到「整理好了」那条通知。
24. AI 整理**提速**：单趟直出的上限 12000 → 20000 字（常见的一节课从「素材卡 + 合并」两轮调用
    变成一轮，等待时间差不多砍一半），分段并发 4 → 6，终稿输出卡 2400 token 上限防止模型
    长篇复述，素材卡输出收窄到 900 token；`clean()` 顺手归一化 Markdown（压掉 `####`、
    给标题补空行、合并连续空行），排版结果更稳定。
25. **截图入口前移**：不再需要「去设置里单独开悬浮截图」——开始记录时自动复用内录的录屏授权
    把圆钮挂出来（`MainActivity.attachShotBall`，先等 `ShotGate` 登记好再挂）；
    纯麦克风录音也会在开始记录这一步顺路要一次授权，用户拒绝照样正常录音；
    `ShotService.begin()` 复用授权时最多重试 5 次 × 250 ms，不再出现「圆钮一闪就没了」。
    记录页新增「课件截图」按钮（`LiveActivity.btnShot`），不用悬浮窗也能截。
26. **排版更清楚**：大节徽标改成跟正文序号一致（正文「一、」→ ①，不再按出现顺序硬编号，
    「知识框架 / 术语表」这类固定栏目改用主色竖条）、大节之间加细线分隔、
    三级标题的 `1.1` 单独用主色标出、时间戳胶囊降成灰底灰字 0.84 倍（它是回头翻录播的索引，
    不该跟知识点抢注意力）、正文行距放宽。
27. **截图落到它自己的时间戳位置上**：本地整理把一节里的要点和截图**按时间戳合成一条时间线**排，
    图就落在「当时正在讲它的那句话」下面（以前是在小节末尾堆一堆）；AI 整理里模型漏放 `[[IMGn]]`
    记号的图，也会按 `[mm:ss]` 挑出时间上最贴近的那一行插进去，只有整篇都没有时间戳时才
    退回文末的「本课图示」兜底。
28. 导出更省心：`.md`、`.html` 和 `shots/` 落在**同一个**「下载/同名文件夹/」里
    （以前 HTML 散在下载根目录、markdown 在子目录，打开「下载」看到一堆文件谁也认不出是一套），
    提示条把两个路径直接写出来；首页列表上方多一行「我的笔记 · 共 N 篇」（搜索时是「搜索到 N 篇」）。
29. 把「录完 → 看整理稿」这条主线拉直：停止保存后**直接进整理稿页**（打开就地做本地整理），
    不再先落在原始转写页；详情页顶部多一颗显眼按钮（没有整理稿时是「整理成知识点笔记」，
    有了就变成「看整理稿」），不用再翻右上角菜单；首页每张卡片直接标「已整理」，
    长按菜单第一项就是一键进整理稿。
30. 截图分析串行化：连拍时视觉请求**排队**跑（以前几张并发打出去，既容易被免费额度限流 429，
    也同时占着好几份 base64 编码的图），排队期间悬浮球上会说明「排队分析课件截图…」。
31. **删除可后悔**：删除从「`deleteRecursively` 一句话」改成**挪进回收站**（`notes/.trash/<id>`），
    放满 7 天才真清（`NoteStore.purgeTrash`，进程起来时扫一次）。首页多选删完给一条能点的「撤销」，
    详情页删完回到列表也有一条；菜单里新增**回收站**页（`TrashActivity`）：一行一篇、写「刚删的 · 5 句」，
    点一下就放回去，右上角「全部恢复 / 清空回收站」，空的时候是一句「回收站是空的」。
    删除后立刻关掉 App 也不怕 —— 那篇还躺在回收站里。
32. **首页更好用**：统计行补上**累计时长**（「共 11 篇 · 累计 17 分钟」），
    右边多一个「只看未整理」，整理完一批之后剩下的那几篇一眼看得见（开关记在设置里）。
33. **多选**：长按任意一篇或菜单进「多选」，顶栏换成「已选 N 篇 / 全选 / AI 整理 / 导出 / 删除」。
    AI 整理升级成**队列**（`DigestJob.enqueue`）：选一片点一下就能去睡觉，一篇接一篇跑，
    通知里写着「《X》· 后面还排着 N 篇」。菜单点「多选」时那一下抬手的点击会被挡掉
    （顶栏一换、列表往上顶，手指抬起来正好会勾中一篇）。
34. 整理稿解析修两处残渣：模型把代码块塞进列表项的写法（`- ```bash`）现在会还原成真正的代码块
    并削掉公共缩进；视觉模型写的 `- > 要点：xxx` 不再原样显示那个「>」。
35. **连点截图不再把录制弄结束** —— 这是 Android 14 起的一条硬规矩：同一个录屏授权只能建一次
    `VirtualDisplay`，第二次会被系统抛 `SecurityException`，而且**顺手把整个授权停掉**，内录跟着一起断
    （真机上就是「点第二下截图，录制没了」）。现在「镜子」（`VirtualDisplay` + `ImageReader`）
    **建一次就长期复用**（`MirrorSlot` 守着这条规矩：只建一次，建失败也不再重试），抓帧从常驻的
    管道里取，顺带每张图都快了一截。
36. 截图这条线的几个手感问题：**没有悬浮窗权限时不再停服务**（通知里的「截图」和记录页那颗按钮
    照常能用），记录页会解释一句并跳去开权限、回来自动把圆钮挂上（`OverlayPerm`，只问一次）；
    圆钮挂出来、转屏、换屏都按当前屏幕收一次边（以前存的是别的时候的坐标，平板竖屏上圆钮会跑到
    屏幕外）；记录页点「课件截图」，结果也会在自家页面上用气泡说一声（以前这里被静音了）。
37. **画面不动也能截图**：镜子常驻之后冒出来的新问题 —— 系统只在画面**有变化**时才推新帧，
    视频一暂停、课件页一停住，临时去要「一帧新的」就只能等到超时（真机上就是屏幕明明亮着、
    气泡却说「截图失败」）。现在最近那一帧一直攥在手里（`FrameSlot`：来新的才换，旧的交给回收），
    要帧时拿不到新的就用手里这张；镜子分辨率按**像素总数封顶**（长宽一起缩、不变形、只降不升），
    合成 / 解码 / 压缩都跟着快一截；转屏、折叠之后给同一块幕布换一张新底片，不新建 `VirtualDisplay`。
38. **「共享范围」别挑错应用**：Android 14 的授权框里有「共享或录制的范围」这一项，某些 ROM
    （这台平板上就是）**每次都默认「单个应用」**：点完「继续」还得再挑一个应用 —— 挑到正在放
    网课的那个 App 时效果最好：截图只有那个 App 的画面、没有状态栏，真机上验过声音也照样内录
    得到（`dumpsys audio` 里那条 REMOTE_SUBMIX 会话是 `not silenced`）；代价是被挑的 App 一旦切到
    后台，系统就不再推帧、那段时间截不到图（`FrameSlot` 会把手里的最后一张兜住）。挑成「网课笔记」
    自己则会整节课 0 句、截图是自家页面；选「整个屏幕」不用挑、任何界面都截得到。现在申请授权前
    会先把这两种选法说清楚，「内录一直没声音」那条提示也改成指向这一条。
39. **「怎么点都截不到」的真凶：监听挂晚了** —— 镜子改成常驻之后，截图偶尔会一帧也等不到
    （真机上复现过两次，日志里都是「grab: no frame」，屏幕却亮得好好的）。根子在顺序：ImageReader
    必须**先 setOnImageAvailableListener、再 createVirtualDisplay / setSurface**。写反了的话，首帧会赶在
    监听装好之前进队列，队列一满（MAX_IMAGES = 3）系统就不再推帧，等到超时也是空的 —— 这是把
    「每张图临时建一次镜子」改成常驻时才踩进去的坑，翻回旧版代码一对就明白。现在建镜子和转屏
    换 surface 都按这个顺序写；另外「一帧都没等到」时还会给同一块幕布换张新底片再要一次
    （比重新建幕布安全：同一个授权第二次 createVirtualDisplay 会被系统直接掐掉）。
40. **截图在记录页当场看得见；AI 分析一句话都不说** —— 以前记录页只有转写，截图要等录完进详情页
    才看得到。现在列表里转写和截图按时间戳混排（`mergeRecordRows`，稳定排序保证同一时刻文字在前），
    点图看大图，还没说明的那张能就地「AI 分析这张图」（动作和详情页共用 `ShotRowActions`，
    `NoteStore.shotsTick` 一发信号列表自己就刷新）。同时把「正在截图…／AI 正在看图…／排队分析…／
    图片已分析」这一串气泡全撤了：点一下只留「已存入《…》」一句，分析在后台默默排队、写完直接进
    笔记 —— 免费视觉模型高峰期排上一两分钟，也不必让人盯着屏幕等。分析失败仍会说一句（不然就成了
    闷声坏事），「还没配看图 Key」只提醒一次。
